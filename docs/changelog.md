# Changelog

## 0.1.0

- Added Niuma code-hint candidates; remaining code hints are tappable (for example, `zt` exposes the `⊙ h` and `☯ j` continuations).
- Four-code candidates can roll over as another letter is typed, including Z-prefix candidates; selecting a hint early resolves the documented rare `zjian` fifth-letter ambiguity.
- Added symbol/number swipe-up actions, emoji-toolbar cleanup, period candidate commit behavior, and Caps Lock support.
- Added a translucent glass-style keyboard surface, candidate appearance controls, gesture editing, candidate associations, and local English completion.
- Added opt-in offline speech recognition with explicit transcript confirmation, plus staging/build tools and source contract tests.

The CodeHints 0.1.0 release was installed and tested on the authorized vivo device before this public source publication; the device's IME settings were preserved. This repository does not contain private device snapshots or serial identifiers.
