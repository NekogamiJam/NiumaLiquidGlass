# Roadmap

The current 0.1.0 feature set has been exercised for several days without further issues reported. This roadmap is intentionally non-committal; future work should be driven by reproducible user feedback.

- Continue manual compatibility checks across Android versions, keyboards/editors and screen sizes.
- Improve reproducibility of native dependency builds and maintain the pinned source/license inventory.
- Review model and third-party redistribution terms when upstream assets or revisions change.
- Expand automated source contracts where they provide stable coverage without requiring private device state.

No additional product issue is currently known from the completed trial period.
